macOS真实整模型CLI（源码路径，无整模型冻结App）
需要macOS arm64、Python3.12+及Apple Command Line Tools；首次准备需互联网，约1GB磁盘。在交付包所在目录执行：

   tar -xzf lastcore-source-85ddad92758d072097de87857f7ed1a229c8f76e.tar.gz
   cd 85ddad92758d072097de87857f7ed1a229c8f76e
   python3 -m venv real-model-runtime/.venv
   real-model-runtime/.venv/bin/python -m pip install cmake==4.1.0 -r node-agent/requirements.txt
   real-model-runtime/.venv/bin/python real-model-runtime/bootstrap.py
   real-model-runtime/.venv/bin/python real-model-runtime/runtime.py --prompt 'What is the capital of France?' --tokens 32 --timeout 60

上述bootstrap会校验固定模型与后端。若Command Line Tools缺失，先按macOS安装界面完成安装。

在私有目录创建worker.json，权限0600；以下仅是占位模板。runtime_root换成刚解压源码内real-model-runtime的绝对路径；首次registration_token由操作员私下配置，不随公开包提供：

   {
     "controller_url": "https://8.134.161.123",
     "registration_token": "REPLACE_PRIVATELY",
     "state_dir": "~/Library/Application Support/LastCore/real-worker",
     "runtime_root": "/absolute/path/to/85ddad92758d072097de87857f7ed1a229c8f76e/real-model-runtime",
     "name": "macos-real-model-worker"
   }

   chmod 600 /absolute/private/worker.json
   real-model-runtime/.venv/bin/python real-model-runtime/worker.py --config /absolute/private/worker.json

保持CLI运行；管理员为该节点分配任务。首次成功注册后可移除配置中的registration_token，保留私有state_dir供凭据复用和恢复。Ctrl-C请求取消清理；以Controller停止确认为准。不要删除进行中账本。

Mac legacy/tiny bundle另有范围
lastcore-node-agent-macos-arm64-unsigned-88a80e3.tar.gz 是macOS14+ arm64的tiny随机小模型分层节点，支持stage/demo，不能当作上述SmolLM2整模型App。解压后需整体保留lastcore-node-agent及_internal，按源码node-agent/desktop/README.md配置私有env并运行preflight；默认loopback endpoint不代表公网可达。它没有Developer ID签名/公证；本轮不扩展签名、商店或自启动。
