LastCore 三分钟展示讲稿（公开资料版）
时间按北京时间。页面步骤是历史说明性回放，不创建新任务。

0:00—0:20  首页：先让观众知道展示什么
画面：标题、云端→本机的路径图、版本与健康入口。
讲稿：
“这是 LastCore 的最小核心预发布。我们把一条完整链路跑通了：云端分配任务，本机运行一个固定模型，再把结果和停止确认交回云端。这里可以看演示，也可以下载文件、查看 API 和公开验收记录。”
操作：指向版本与公网 API 状态；健康接口只显示当前可达性。

0:20—0:55  生成成功：回放一个已经证明的结果
画面：选择‘生成成功’，点击‘回放这条真实记录’。
讲稿：
“这次回放的是已经验收的真实记录。任务交到 Mac 上，原生后端运行固定 SmolLM2，返回的结果摘要是 Paris。接下来不只是显示一句答案，云端还保存了任务结束和停止确认。页面的动画解释这条路径，不会再次运行模型。”
操作：依次指向分配、本机生成、结果和停止确认四步。

0:55—1:30  超时与取消：看清怎样结束
画面：依次切换‘超时停止’和‘取消清理’。
讲稿：
“另两条路径也已经验证。达到执行期限时，后台进程会停止并回收；执行中取消时，会停止执行、清理结果，再确认结束。成功、失败和取消都有各自的状态。这些记录说明的不只是能生成，还包括能停下来。”
操作：突出最后一步停止确认，不展示虚构计时器或实时日志。

1:30—1:55  Android：展示已经完成的范围
画面：Host JVM/JNI 卡片与 APK 下载项。
讲稿：
“Android 已经有可以下载的 arm64 APK。和 Android 同源的 worker 与实际主机 JNI，完成过真实云任务生成和停止确认。这里明确标成主机 JNI，因为手机真机、系统生命周期和 Keystore 还没有实测，不能把两者混为一谈。”
操作：指向‘Host JVM/JNI 已验证’和‘真机待验证’标签。

1:55—2:20  tiny 链路：解释第二种已有客户端
画面：本地双节点 tiny 示意与 Mac 客户端说明。
讲稿：
“已有的 Mac frozen 客户端服务另一条路径：两个节点接成 tiny 分层链路，输出和单机参考逐字节一致，也验证了取消和凭据重启。这是本地小模型验证。真正的 SmolLM2 整模型运行使用独立 Python CLI，两条路径分别说明。”
操作：指向‘tiny 本地’与‘整模型 CLI’标签，避免说成预训练模型多设备分层。

2:20—3:00  下载与来源：让展示能够交给别人
画面：版本附件、快速指南、API 文档、演示包。
讲稿：
“最后，这个预发布不只是一张效果图。源码、客户端、哈希、完整许可证和使用指南都有公开入口。Debug APK 是开发签名，release APK 尚未签名。演示包另外包含页面、真实页面渲染截图和这份讲稿；不包含模型、密钥或任何控制 token。看完以后，可以直接下载、核对来源，再按指南运行。”
操作：打开 Release 或 /docs；演示包上线后展示下载。演示页面不填写凭据，不调用任务创建接口。
